## 机房 IP 和住宅 IP，差价买的是同一件东西

普通 VPS 给你的 IP 归属写着 hosting、datacenter、cloud。这类 IP 便宜、带宽大、性能强，跑网站、跑爬虫都没问题。问题是 TikTok、Instagram、WhatsApp 营销号、亚马逊卖家后台、Netflix 区域解锁、ChatGPT 地区校验这些平台，第一件事就是查 IP 归属。数据中心段基本进了公开黑名单库，账号权重从一开始就被砍。

住宅 IP 的归属写成某个真实运营商的宽带用户段，平台看到的是「纽约某公寓里一个普通家用宽带用户」。这就是它贵的原因，也是它唯一的存在意义。LisaHost 主打的「双 ISP 家宽住宅原生 IP」就是这个品类，线路覆盖美国、香港、台湾、新加坡、日本、英国、韩国、越南，其中美国住宅 IP 是主推方向，因为 TikTok 美区、亚马逊、ChatGPT、Netflix 美区要的都是美国本土 IP。

代价也很明确：住宅带宽普遍只有 50–100Mbps，流量按 TB 计而不是不限量。拿它跑视频站、镜像站是选错了工具，不是产品不行。
